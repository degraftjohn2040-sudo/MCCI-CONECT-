# Prioritized roadmap

1. **Safety and governance:** agree church-specific role/scope matrix, privacy/legal basis and data lifecycle; threat model, MFA, password recovery, account/session administration, distributed rate limits, encrypted storage, audit integrity and review.
2. **Operational readiness:** expand and rehearse the initial additive migrations, reproducible dependency lock, deployment configuration, observability, encrypted scheduled backups, restore drills, CI/browser/accessibility and realistic load testing. Do not use real data until approved.
3. **Core workflows:** comprehensive member deduplication, consent recording and retention, scoped communities and individual attendance, pastoral follow-up with strict confidentiality.
4. **Engagement:** privacy-reviewed prayer requests, forms/templates/shareable links/responses and spreadsheet-like records; messaging launch actions with consent and audit.
5. **Integrations and insights:** Google Workspace with least-privilege OAuth, a server-side AI integration with managed secrets and explicit data controls, reporting/analytics, and an Android strategy. Validate each provider before claiming support.

Each stage requires product acceptance, security review, tests, migration and rollback planning. These items are plans, not existing functionality.
